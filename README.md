# Build with Phi

A responsive student dashboard and course platform for browsing courses and keeping track of learning progress.

## Features

- Course dashboard with status filters for all, in-progress, and completed courses
- Student pages for courses, payments, and profile
- Shared navigation and dashboard layout
- Responsive layouts for desktop, tablet, and mobile
- Client-side data fetching support with Axios

## Tech Stack

- React 18
- React Scripts 5 (Create React App)
- Axios
- CSS
- React Testing Library and Jest DOM for component testing

## Project Structure

The exact file names may differ as the project evolves. A typical Create React App layout is:

